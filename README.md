# API 测试套件

针对 OpenAI 兼容 API 的全量自动化测试脚本，覆盖功能、性能、稳定性、长上下文、准确性等维度。

## 项目结构

```
test/
├── .env                # API 配置（Base URL、Key、Model）
├── .gitignore          # Git 忽略规则
├── full_test.py        # 全量测试脚本（统一入口）
├── full_report.xlsx    # 全量测试报告（自动生成，不提交 Git）
├── README.md           # 本文档
```

## 快速开始

### 1. 安装依赖

```bash
pip install python-dotenv requests openpyxl
```

### 2. 配置 API

编辑 `.env` 文件，填入你的 API 信息：

```env
BASE_URL=https://your-api.example.com/v1
API_KEY=sk-your-key-here
MODEL=gpt-4o
ENABLE_THINKING=false
```

### 3. 运行测试

```bash
# 全量测试
python full_test.py

# 指定采样次数（默认 5）
python full_test.py --samples 10

# 只跑部分用例
python full_test.py --only FUNC-001,ACC-001,STAB-001

# 组合使用
python full_test.py --samples 10 --only FUNC-001,PERF-001
```

## 测试报告

每次运行后自动生成 Excel 报告：

- **全量测试**：`full_report.xlsx`
- **选测部分用例**：`full_report_{模型名}_{用例ID}.xlsx`（互不覆盖）

报告包含：
- 整体通过率
- 每个用例的通过状态、详细描述、性能指标
- 按类别分组的汇总

## Bug 修复日志

### 2026-07-24

- 修复部分 API 网关主动断开 `python-requests` 默认连接，导致 `RemoteDisconnected` 的问题：请求头增加通用 `User-Agent`。
- 同一错误出现两次是因为性能采样会分别发送一次非流式请求和一次流式请求。

## 注意事项
- `.env` 文件包含 API Key，请勿提交到公开仓库
- 长上下文和超长输出测试耗时较长，建议先用 `--only` 选测
- 并发测试可能触发限流（429），属于正常现象
- 深度思考（`ENABLE_THINKING=true`）会消耗输出 token 配额，部分测试的 `max_tokens` 建议适当调大
- 不同模型对 `max_tokens`、`response_format` 等参数支持度不同，切换模型时注意调整
- MiniMax-2.5等模型仅支持深度思考模式，务必改成true
- 其他模型支持深度思考模式，建议改成false
